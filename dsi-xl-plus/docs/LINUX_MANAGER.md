# Linux Manager — future work

The companion application is planned for Phase 9 and is not implemented in Phase 1. Its intended target is Linux Mint/Xfce on modest hardware, using lightweight native technology such as Python/GTK.

The host can later handle expensive artwork conversion, indexing, backup verification and staged updates. The console should retain bounded lightweight operations and offline launch access. Any future Manager must protect saves, avoid automatic formatting/deletion, distinguish application rollback from user-data recovery, and preserve source/license provenance.
