# Safe Mode boundary — not implemented

Phase 1 implements config fallback and a policy state that suppresses optional features. It does not implement a Safe Mode key combination or independent recovery interface.

Phase 6 must detect a verified nonconflicting startup chord before optional resources, handle normal and direct-selector entry, and load a minimal interface independent of the assets/database it repairs. Existing ABXY reset, SELECT shortcuts, B autorun behavior and A+RIGHT booter behavior must be preserved and tested. No new chord is reserved without that audit.

The existing settings page or another upstream theme is not an independent recovery environment. Shared filesystem initialization runs before XL+ hooks. External baseline restoration remains necessary for unreadable cards or damaged application/boot files. Safe Mode does not justify NAND writes or automatic bootloader installation.
